# 📱 Mobile Sales Analysis Dashboard – Power BI

## 📊 Project Overview

This project is an interactive **Mobile Sales Analysis Dashboard** created using **Microsoft Power BI**.

The dashboard provides a comprehensive view of mobile sales performance, helping users analyze sales trends, revenue, quantity sold, customer behavior, and product performance through interactive visualizations.

The objective of this project is to transform raw sales data into meaningful business insights and support data-driven decision-making.

---

## 🎯 Project Objectives

- Analyze overall mobile sales performance
- Identify top-performing mobile brands and models
- Analyze sales and revenue trends
- Understand customer purchasing behavior
- Compare sales across different regions
- Identify high-performing products
- Create an interactive and user-friendly business dashboard

---

## 🛠️ Tools & Technologies

- **Power BI**
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and calculations
- **Microsoft Excel / CSV** – Data source
- **Data Visualization** – Charts, KPIs, slicers and interactive reports

## 🔍 Key Insights

> **Note:** The insights below should be updated with the actual values from the dashboard.

### 1. Overall Sales Performance
The dashboard provides an overview of total sales, revenue, and quantity sold, allowing overall business performance to be monitored quickly.

### 2. Top-Performing Brands
The analysis identifies the mobile brands contributing the highest sales and revenue, helping determine which brands have the strongest market performance.

### 3. Best-Selling Models
Certain mobile models contribute significantly to overall sales. Identifying these models helps understand customer preferences and product demand.

### 4. Sales Trend
The time-based analysis shows how mobile sales change across different months and periods, helping identify periods of higher and lower demand.

### 5. Regional Performance
Sales performance varies across regions. The dashboard helps identify high-performing and low-performing regions for better sales planning.

### 6. Customer Purchasing Behavior
The dashboard provides insights into customer purchasing patterns and helps identify products and categories that attract greater customer demand.

### 7. Business Opportunities
The analysis can be used to identify high-demand products, strong-performing regions, and sales trends that can support inventory planning and marketing decisions.
